## 主要研究方向

1. **排队—库存系统建模优化**：研究带服务员休假、双源补货的排队库存模型，采用 QBD 矩阵解析、深度强化学习等方法，面向供应链、医疗服务场景开展系统性能分析与调度策略优化。
2. **医疗大数据与生存分析**：针对区间删失、竞争风险医疗数据，构建多任务深度生存模型，开展中老年慢性病共病关联挖掘与风险预测研究。
3. **智能优化与机器学习算法**：开展群智能优化、深度学习算法改进研究，应用于无人机路径规划、医学影像识别、时序预测、生物质预处理建模等场景。
